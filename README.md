# j.gut — illustration portfolio

Portfolio site for José Gutierrez (j.gut): a cinematic scroll-driven hero followed by a light gallery of illustrations.

Built with Next.js 16, TypeScript, Tailwind CSS 4, GSAP + ScrollTrigger, Lenis and Canvas 2D. Deployed on Vercel.

```bash
npm install
npm run dev          # http://localhost:3000
npm run build
npm run optimize:frames
```

Project conventions, the Git checkpoint workflow and the confirmed intent live in [`CLAUDE.md`](CLAUDE.md) and [`docs/intent/portfolio.md`](docs/intent/portfolio.md).
